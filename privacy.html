Política de Privacidad

Última actualización: 10 de septiembre de 2026 • Versión 1.1

En ToolTip AI (Dixi3 Lqbs) respetamos tu privacidad. Esta política describe qué datos toca la aplicación de escritorio para Windows 11 y la landing/demo web.

1. Principio

No operamos un backend intermedio de capturas ni vendemos datos personales. El análisis con IA ocurre solo cuando tú lo pides, contra la API de Google Gemini que configuras con tu propia clave (Bring Your Own Key).

2. Capturas de pantalla

  • Local: el recorte vive en memoria RAM; no se escribe en disco salvo petición explícita del usuario.
  • API de IA: al analizar, la imagen y el contexto se envían cifrados (HTTPS/TLS) a los servidores oficiales de Google (Generative Language API). Google aplica sus propias políticas de datos.
  • Sin servidor propio de capturas: Dixi3 Lqbs no recibe ni almacena tus capturas.

3. Clave de API

En la app de escritorio (Microsoft Store / MSIX), la clave se cifra con Windows DPAPI (ProtectedData, ámbito de usuario) y se guarda cifrada en %APPDATA%\TeachMeAI\config.json. No se envía a Dixi3 Lqbs; solo autentica llamadas a Google.

En la landing/demo web, si pegas una clave, se usa solo en memoria de la sesión y no se persiste en localStorage.

4. Telemetría y anuncios

La versión actual no incluye publicidad, SDKs de analítica de terceros ni telemetría de uso hacia Dixi3 Lqbs.

5. Permisos y atajos

  • Captura de pantalla: para recortar el área a analizar.
  • Atajos globales: Ctrl+Shift+A (recorte), Ctrl+Shift+D (radar), Ctrl+Shift+C (ajustes). El hook de teclado de bajo nivel solo es respaldo de esas combinaciones exactas.
  • Bandeja del sistema: para estar disponible sin interrumpir.
  • Internet: solo para la API de IA que configures.

6. Módulo y Aplicación ToolTip AI Translate

Para la aplicación complementaria ToolTip AI Translate, se aplican idénticos principios de soberanía y privacidad:

  • Texto traducido: Se envía mediante TLS/HTTPS directamente a la API oficial configurada (Microsoft Azure Translator o Google Gemini). Dixi3 Lqbs no opera servidores intermedios ni almacena tus palabras.
  • Protección estricta de contraseñas: El extractor comprueba la propiedad nativa IsPassword. Si el cursor se sitúa sobre un campo de contraseña, la lectura se cancela de inmediato y se bloquea la captura OCR.
  • Reconocimiento óptico local (OCR): El motor Windows.Media.Ocr opera de forma 100% local en tu dispositivo; las imágenes no se transmiten a la nube.
  • Claves cifradas: Las credenciales de traducción se almacenan cifradas con Windows DPAPI en %APPDATA%\ToolTipAITranslate\settings.json.

7. Contacto y Soporte

Dudas sobre privacidad o reporte de incidentes: github.com/dixi3stdgdl-design/TeachMe-AI/issues
