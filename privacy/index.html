Política de Privacidad

Última actualización: Septiembre 2026 • Dominio Oficial: tooltip-ai.com

En Tooltip-ai (Dixi3 Labs) la privacidad y soberanía de datos del usuario son principios arquitectónicos no negociables. Esta política describe con transparencia técnica el tratamiento de datos en el software para Windows 11 y servicios asociados bajo tooltip-ai.com.

1. Principio de Inferencia Directa (Bring Your Own Key)

No operamos servidores intermediarios para almacenar, inspeccionar ni monetizar tus capturas de pantalla o textos. El análisis visual e inferencia ocurre directamente desde tu cliente local hacia la API oficial de Google Gemini u otros proveedores de tu elección.

2. Tratamiento Efímero de Pantalla

  • Almacenamiento en Memoria RAM: Los recortes generados mediante Ctrl + A residen exclusivamente en memoria volátil mientras dura la consulta.
  • Cifrado TLS 1.3: Las imágenes transmitidas a la API de IA viajan a través de túneles HTTPS con cifrado de extremo a extremo.
  • Cero Telemetría Visual: Dixi3 Labs no recibe copia alguna de tus capturas.

3. Seguridad de Credenciales (Windows DPAPI)

Tus claves de API se cifran localmente mediante el subsistema criptográfico nativo de Windows (Data Protection API - DPAPI). Ningún proceso sin privilegios de tu usuario puede extraerlas.

4. Módulos de la Suite Tooltip-ai

  • Tooltip-ai Translate (/translate): El reconocimiento óptico (OCR) se ejecuta 100% de forma local mediante Windows.Media.Ocr. Se enmascaran automáticamente campos clasificados como IsPassword.
  • Tooltip-ai Aura (/aura): El radar analiza coordenadas relativas de interfaz en tiempo real sin guardar histórico fuera de la sesión.
  • Tooltip-ai Voice (/voice): La síntesis utiliza los motores neuronales de Windows 11 en tu procesador local.

5. Contacto y Soporte

Para auditorías de código abierto o reportes de seguridad: github.com/dixi3stdgdl-design/TeachMe-AI/issues
