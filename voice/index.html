public void SpeakVerdictAsync(string technicalExplanation, VoiceCadence cadence) {
    using (var synth = new SpeechSynthesizer()) {
        // 1. Configurar voz neural en español con entonación adaptada
        synth.SelectVoiceByHints(VoiceGender.Female, VoiceAge.Adult, 0, new CultureInfo("es-ES"));
        synth.Rate = (cadence == VoiceCadence.Gamer) ? 2 : 1;
        
        // 2. Aplicar Audio Ducking en el mezclador de Windows para atenuar fondo
        AudioSessionController.ApplyDucking(level: 0.40f);
        
        // 3. Reproducción asíncrona sin bloquear el hilo de entrada
        synth.SpeakCompleted += (s, e) => AudioSessionController.RestoreVolume();
        synth.SpeakAsync(technicalExplanation);
    }
}

Por Qué los Motores TTS Comunes Fracasan con Código

La mayoría de sintetizadores de voz están hechos para audiolibros o GPS. Voice está diseñado para ingenieros y gamers:

Tokenizador

Lectura Fonética Inteligente

Un sintetizador convencional lee NullReferenceException como un trabalenguas incomprensible. Voice preprocesa el texto con un parser fonético que lo pronuncia de forma limpia y didáctica.

  • Descompone nombres en camelCase y snake_case
  • Lee direcciones de memoria hexadecimales con brevedad
  • Omite símbolos sintácticos irrelevantes para no fatigar

Ducking

Atenuación Automática de Fondo

No tienes que pausar tu música de Spotify ni apagar los altavoces de tu juego. Voice envía una señal al bus WASAPI de Windows para atenuar suavemente el fondo mientras dura el dictamen.

  • Transición de volumen suave sin chasquidos
  • Restauración inmediata al terminar la oración
  • Compatible con auriculares, altavoces y sistemas 7.1
